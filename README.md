# SPORTHUB DAILY

Static editorial website for GitHub Pages.

## Quick setup
1. Create a new GitHub repository, for example `sporthubdaily`.
2. Upload all files from this folder to the repository root.
3. Open Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Your site will be available at `https://USERNAME.github.io/sporthubdaily/`.

## Where to edit content
- `assets/js/content.js` — categories, articles, shop URL.
- `assets/css/style.css` — colors, spacing, typography, effects.
- `index.html` — homepage sections.
